# Camera_PFE Senai

## Sobre o projeto

O Camera_PFE é um projeto que desenvolvi para praticar meus conhecimentos em HTML, CSS e JavaScript, utilizando a câmera do próprio dispositivo.

A ideia foi criar uma página em que o usuário pudesse ligar a câmera, tirar uma foto e aplicar alguns efeitos antes de salvar a imagem.

## Funcionalidades

- Ligar e desligar a câmera.
- Tirar fotos usando a câmera do dispositivo.
- Aplicar efeitos visuais na imagem.
- Adicionar uma identificação personalizada à foto.
- Registrar a data e o horário da captura.
- Visualizar o resultado antes de salvar.
- Baixar a imagem final.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização e organização dos elementos.
- **JavaScript:** funcionamento da câmera, aplicação dos efeitos e processamento das imagens.
- **Canvas API:** edição da imagem e inclusão das informações na foto.
- **MediaDevices API:** acesso à câmera do dispositivo.
